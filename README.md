# Adidas Sales Data Analysis

## Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on Adidas sales data to uncover meaningful business insights and understand sales performance across different dimensions.

The analysis explores sales trends and performance across regions, products, retailers, and sales methods to support better business understanding and data-driven decision-making.

## Objectives
- Analyze Adidas sales performance.
- Identify the highest-performing regions and products.
- Compare sales across different retailers.
- Explore the impact of different sales methods.
- Extract meaningful business insights from the dataset.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Project Workflow

### 1. Data Cleaning
- Inspected the dataset structure and data types.
- Identified and removed irrelevant or junk rows.
- Prepared the dataset for further analysis.

### 2. Exploratory Data Analysis
Performed analysis across several dimensions:
- Regional sales performance.
- Product-level sales analysis.
- Retailer performance comparison.
- Sales method analysis.
- Total sales analysis.

### 3. Data Visualization
Used Matplotlib to create visualizations that help identify patterns, compare performance, and communicate findings.

## Key Insights
- The West region recorded the highest sales value in the regional analysis.
- Sales performance varies across products, retailers, and sales methods.
- Comparing different business dimensions helps identify sales patterns and performance differences.
